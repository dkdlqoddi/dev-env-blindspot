## 2026-09-14 11:25 — 워커는 세션 모델을 상속하고 checker는 flash 유지

- 검토한 대안: 에이전트 파일에 gemini-3.8-flash-high 같은 구체 모델 이름 고정(버전이 바뀔 때마다 공유 저장소를 고쳐야 하고 미실측) / --effort high(모델 이름 쪽이 명시적)
