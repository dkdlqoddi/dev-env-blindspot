머지 전 퀴즈: Claude Code 계획 · Antigravity 스웜 실행 분업

대상: docs/core/specs/swarm-handoff.md · 기준: 392598a (main)

변경 요약

구현 작업을 두 도구에 나누어 맡기는 장치가 생겼습니다. 생각이 필요한 일은 Claude Code의 강한 모델이 합니다. 인터뷰, 점검, 설계, 계획, 감사, 보고가 여기에 속합니다. 정해진 대로 고치는 일은 Antigravity의 빠른 모델 여러 개가 동시에 합니다. 두 도구는 같은 폴더의 파일로만 대화합니다.

계획 스킬은 확정된 명세가 있어야만 계획을 씁니다. 요청 문장만으로는 계획을 쓰지 않습니다. 계획은 작업마다 지시서(브리프) 한 장을 만듭니다. 지시서에는 고칠 파일, 할 일, 끝났다고 볼 조건, 검사 명령이 전부 적힙니다. 동시에 도는 작업들은 서로 다른 파일만 고칩니다. 검사 스크립트가 실행 전에 이것을 확인하고 겹치면 막습니다.

작업은 묶음(웨이브) 단위로 동시에 실행됩니다. 한 묶음이 끝나면 검사 에이전트가 전체 검사를 돌립니다. 검사가 실패하면 한 번 다시 시도합니다. 그래도 실패하면 거기서 멈추고 다음 묶음으로 가지 않습니다. 다시 계획하는 일은 Claude Code가 합니다. 묶음마다 변경이 커밋으로 남습니다.

Antigravity 쪽 하위 에이전트는 자기 지시서에 적힌 파일만 고칩니다. 질문하지 않고, 계획을 고치지 않습니다. 지시서 밖의 파일을 고쳐야 하면 고치지 않고 결과 파일에 적고 멈춥니다. Claude Code의 검토 스킬은 하위 에이전트의 "완료" 주장을 실제 변경과 대조해 판정합니다. 하위 에이전트가 내린 선택은 작업 노트로 옮겨집니다. 그다음 기존 보고 스킬과 이 머지 전 퀴즈로 넘어갑니다.

파일을 직접 고치는 에이전트는 Antigravity의 하위 에이전트 하나뿐입니다. Claude Code 쪽 에이전트는 예전처럼 파일을 고치지 않습니다. 기존 다섯 스킬과 다섯 에이전트의 이름과 수는 그대로입니다. 계획 폴더(docs/swarm)는 퀴즈 통과 뒤 작업 노트와 함께 지워집니다.
