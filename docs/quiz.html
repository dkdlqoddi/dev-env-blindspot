변경 요약

작업마다 구현(swarm-worker), 검증(swarm-verifier), 리뷰(swarm-reviewer) 세 에이전트가 협업 스쿼드를 구성합니다. 에이전트들은 메시지를 주고받으며 코드와 작업의 완성도를 올립니다.

구현 에이전트가 코드를 고치면 먼저 검증자에게 테스트 검증을 요청합니다. 검증을 통과한 뒤에는 리뷰어에게 규칙과 명세 부합성 검토를 받아 승인을 얻습니다.

무한 루프를 방지하기 위해 스쿼드 안의 대화는 최대 3회 턴으로 제한됩니다.

작업 중 생성된 계획과 결과 등의 중간 문서는 작업 완료 시 완전 삭제하여 남기지 않습니다. 최종적으로 남는 산출물은 규칙, 맵, 상세 명세로 이루어진 살아있는 3계층 문서로 고정됩니다. 모든 과정이 끝나고 퀴즈를 통과해야 최종 머지가 가능합니다.
