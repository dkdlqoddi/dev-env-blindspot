머지 전 퀴즈: 모델 고정 (Claude Code Opus xHigh · Antigravity Flash High)

대상: docs/core/specs/swarm-handoff.md · 기준: ad5564d (claude-antigravity-cowork)

변경 요약

이번 변경은 두 도구가 쓰는 모델을 고정합니다. Claude Code는 강한 모델인 Opus를 가장 깊게 생각하는 단계(xHigh)로 씁니다. Antigravity는 Gemini 3.8 Flash의 높은 등급(High)만 씁니다. 중간 단계(medium)는 어디에서도 쓰지 않습니다.

Claude Code 쪽은 설치 스크립트가 프로젝트 설정 파일에 Opus와 xHigh를 적어 둡니다. 프로젝트 설정에 다른 모델이 이미 적혀 있으면 그 값을 지우지 않고 알림만 보여 줍니다. 머지 판정에 쓰이는 두 에이전트도 Opus xHigh로 고정했습니다. 코드 탐색 에이전트 둘과, 문서와 검사 명령을 확인하는 에이전트 둘은 사용량을 아끼려고 더 가벼운 모델을 그대로 씁니다.

Antigravity 쪽은 실행 명령에 높은 등급 모델과 높은 생각 단계를 함께 적습니다. 구현 에이전트와 검사 에이전트가 모두 그 실행 명령의 모델을 물려받습니다. 예전에는 검사 에이전트가 설정 파일에 적힌 가벼운 모델로 따로 돌았습니다. 생각 단계를 중간(medium)으로 주면 모델 등급과 충돌해 실행이 아예 시작되지 않습니다. 앱에서 실행할 때는 모델 목록에서 높은 등급을 직접 골라야 합니다.
