변경 요약

계획부터 실행까지 모든 과정이 Google Antigravity 단독으로 진행되도록 통합되었습니다. Claude Code 의존성과 관련 설정 파일이 완전히 제거되었습니다. 스킬 8종과 서브에이전트 8종은 Antigravity 표준 규격으로 일원화되었습니다.

판단과 설계는 Antigravity 메인 세션의 강한 모델이 맡습니다. 인터뷰, 사각지대 점검, 명세 작성, 스웜 계획이 여기에 속합니다. 구현과 검증은 Antigravity의 빠른 서브에이전트 여러 개가 병렬로 합니다.

소비 프로젝트는 install.sh 한 번으로 필요한 스킬과 에이전트를 연결합니다. 프로젝트 가이드는 ANTIGRAVITY.md와 AGENTS.md로 제공됩니다.

파일을 고치는 에이전트는 여전히 swarm-worker 하나뿐입니다. 그것도 자기 지시서에 적힌 소유 파일 안에서만 고칩니다. 다른 모든 탐색과 검증 에이전트는 읽기 전용입니다. 모든 과정이 끝나면 변경 사항을 계층 문서에 반영하고 퀴즈를 거쳐 머지합니다.
