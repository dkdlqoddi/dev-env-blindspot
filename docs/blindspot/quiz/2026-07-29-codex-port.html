Codex 전용 환경은 다섯 작업 흐름과 다섯 역할 도우미를 설치합니다.

예약된 항목만 갱신하며 기존 프로젝트의 다른 설정은 보존합니다.

설치 결과를 저장할 관리 폴더가 외부를 가리키면 변경 전에 설치를 중단합니다.

시작 자동화가 실행되지 않아도 안내 문서가 작업 규칙의 안전망을 제공합니다.

필수 도우미가 처음 거부되면 자리를 기다려 재시도합니다.

계속 시작할 수 없을 때만 주 작업자가 같은 전체 지침과 입력으로 대신합니다.

현재 검사는 실제 모델이 각 역할을 수행하는 전체 과정까지 포함하지 않습니다.

사용자가 퀴즈를 모두 맞혔다고 확인하기 전에는 변경을 합칠 수 없습니다.
